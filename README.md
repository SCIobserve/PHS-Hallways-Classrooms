# PHS Hallways & Classrooms

Visit tracker for Peekskill High School hallways and classrooms. Static PWA (index.html + sw.js) hosted on Firebase, data stored in a Google Sheet via Apps Script (appsscript.js).

Deploys to Firebase Hosting automatically on every push to `main`.
Bump the cache name in `sw.js` on every `index.html` change or phones keep the old version.
